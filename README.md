# Python Log Analyzer

A Python-based authentication log analysis tool designed to identify failed login attempts and detect repeated authentication failures from individual IP addresses.

## Overview

This project demonstrates basic security log analysis using Python. It processes simulated authentication events, identifies failed login attempts, counts failures by IP address, and flags repeated failures for further investigation.

## Features

- Authentication event analysis
- Failed login detection
- IP-based failure counting
- Identification of repeated login failures
- Automated security report generation
- Report export to a text file

## Technologies Used

- Python 3
- Google Colab
- GitHub

## Execution

The program can be executed using Python 3 or Google Colab.

## Output

The analyzer generates a security report containing:

- Total log entries
- Total failed login attempts
- Failed login counts by IP address
- IP addresses with repeated failed login attempts

## Learning Objectives

- Understand authentication log analysis
- Practice Python lists and dictionaries
- Apply conditional statements and loops
- Perform basic security event analysis
- Generate automated reports

## Disclaimer

This project uses simulated authentication logs for educational purposes. Repeated failed login attempts are indicators requiring investigation and do not independently confirm malicious activity.
